# 2분 데모 영상 스크립트 (초안)

화면은 위에서 아래로 한 번 스크롤한다. 숫자는 `docs/portfolio/numbers.md`(결과 파일 출처)와 같다. 말할 문장은 약 560자로, 보통 속도(분당 280자 안팎)면 2분에 맞는다.

**녹화 전 준비**
- 데스크톱 브라우저 폭 1440, 배포 주소 또는 로컬(`streamlit run streamlit_app.py`)
- 첫 방문 가이드는 장면 1에서 보여 준 뒤 닫는다
- 03의 AI 설명은 저장된 설명(실험 때 만든 1회차)을 쓴다. 실시간 설명 버튼은 누르지 않는다(키·한도에 따라 결과가 달라짐)
- 시리즈 11을 쓴다: 급변·치우침·추세가 한 화면에 다 있고, 04 사례 해설 2와 이어진다

## 고를 것 (사용자 결정)
- 장면 5의 모델 비교 문장: 지금은 "큰 모델은 맞혔지만 느리다"로 적었다. 비용을 넣으려면 결과 파일에 없는 숫자라 출처 확인이 먼저다 (`numbers.md` 마지막 절)
- 시간이 넘치면 장면 2(01 문제 상황)를 빼고 장면 1에 한 문장으로 합친다
- 장면 3의 규칙 설명은 화면 규칙 표 문구와 맞출 것 — 녹화 전에 시리즈 11 표를 보고 "아홉 점" 등 표현을 다시 확인

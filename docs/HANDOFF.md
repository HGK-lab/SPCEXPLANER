- 결과 파일 캐시(`st.cache_data`)에 만료가 없어, 앱을 띄운 채 실험을 다시 돌리면 앱을 다시 시작해야 새 숫자가 보인다 (배포는 푸시마다 재시작)
- 하루 실시간 호출 수 카운터는 세션 사이에서 잠금 없이 더한다 (동시에 누르면 한두 번 더 허용될 수 있음)
- 관리도 라벨 폭은 IBM Plex Sans KR 기준 어림값이라, 글꼴을 못 받아 다른 글꼴로 그려지면 좁은 화면에서 겹칠 수 있다

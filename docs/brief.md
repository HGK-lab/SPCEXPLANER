# SPC 설명기 - 프로젝트 브리프

## 목적
SK하이닉스 AI 해커톤 2026 지원용 포트폴리오. 마감 2026-09-28 17시.
구현은 9/26까지 끝나야 함. 기능 욕심보다 "작동 + 검증 가능"이 최우선.

## 문제
반도체 공정 엔지니어는 관리도를 눈으로 보고 이상을 판단하며,
"무엇부터 점검할지"는 경험에 의존한다.

## 확정된 설계 원칙
- 판정 = 규칙(정확성), 설명 = LLM(해석력). 역할을 절대 섞지 않는다.
- 대상 패턴 3가지만: 급변(관리한계 밖 1점), 추세(6점 연속 상승/하강), 치우침(9점 연속 평균 한쪽)
- 예시 공정: 증착 막 두께, 목표 100nm, 관리한계 약 97~103nm
- 배포: Streamlit Community Cloud. LLM 결과는 캐시 우선 표시, 실시간 호출은 제한.

## 반드시 들어가야 할 기능
1. 가상 데이터 생성기: 정상 데이터 + 위 3패턴을 위치를 기록하며 심기 (정답 라벨 포함)
2. 규칙 판정: 오픈소스 라이브러리 우선 검토 (pycontrolcharts, shewhart 후보)
3. LLM 설명: 판정 결과(JSON)를 받아 "어떤 패턴 / 점검 우선순위 / 근거 규칙" 출력
4. 검증 리포트:
   - 규칙 판정 탐지율 (심은 이상 대비)
   - LLM 단독 판정 탐지율 (비교 실험, 역할 분리의 근거)
   - LLM 설명이 규칙 결과와 어긋난 사례 기록
5. 간단한 UI 또는 리포트 출력 (데모 영상 촬영용)

## 제외 (YAGNI)
- 로그인, DB, 실시간 스트리밍, Nelson 규칙 8개 전부 구현

## 개발자 상황
- 제조 도메인 지식은 최근 학습함. 코딩은 Claude Code에 주로 맡김.
- 모든 코드에 한국어 주석, README에 실행 방법 필수.
